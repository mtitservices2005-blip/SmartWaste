# downloads/

Aquí se publica el APK de SmartWaste Conductor para la descarga directa (`/descargar`). No se edita a mano:
`node scripts/publish-apk.mjs --apk <ruta> --version-name 1.0.1 --version-code 2026103102` copia el APK como
`SmartWaste-Conductor.apk` y escribe `version.json` (versión, fecha, tamaño y SHA-256). Ver `docs/DRIVER_APP_DISTRIBUCION.md`.
